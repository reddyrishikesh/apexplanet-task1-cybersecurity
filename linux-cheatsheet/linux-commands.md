# Linux Commands Cheat Sheet

## File System Navigation

### pwd
Shows the current working directory.

Example:
pwd

### ls
Lists files and directories.

Example:
ls

### cd
Changes the current directory.

Example:
cd Documents

### cd ..
Moves one directory up.

Example:
cd ..

### mkdir
Creates a new directory.

Example:
mkdir cybersecurity

## File Management

### touch
Creates an empty file.

Example:
touch test.txt

### rm
Removes a file.

Example:
rm test.txt

### rmdir
Removes an empty directory.

Example:
rmdir testfolder

## File Permissions

### chmod
Changes file or directory permissions.

Example:
chmod 755 script.sh

### chown
Changes file ownership.

Example:
sudo chown kali test.txt

## Package Management

### apt
Used to install, update, and manage packages.

Example:
sudo apt update

### dpkg
Used to manage Debian packages.

Example:
dpkg -l

## Networking Commands

### ifconfig
Displays network interface information.

Example:
ifconfig

### ping
Tests network connectivity.

Example:
ping -c 4 8.8.8.8

### netstat
Displays network connections and network statistics.

Example:
netstat -tn

### traceroute
Shows the path packets take to reach a destination.

Example:
traceroute google.com

## Summary

These Linux commands were practiced during the cybersecurity lab to understand file management, permissions, package management, and basic network troubleshooting.
