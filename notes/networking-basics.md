# Networking Basics

## OSI Model

The OSI model has seven layers:

1. Physical – Transmits raw bits over a physical medium.
2. Data Link – Handles frames and MAC addresses.
3. Network – Handles IP addressing and routing.
4. Transport – Provides end-to-end communication using TCP and UDP.
5. Session – Manages communication sessions.
6. Presentation – Handles data format, encryption, and compression.
7. Application – Provides network services to applications.

## TCP/IP Model

The TCP/IP model consists of four layers:

1. Network Access
2. Internet
3. Transport
4. Application

## DNS

DNS (Domain Name System) translates domain names such as google.com into IP addresses.

## HTTP and HTTPS

HTTP is used for communication between web browsers and web servers.

HTTPS is the secure version of HTTP and uses TLS encryption to protect data.

## IP Addressing

An IP address identifies a device on a network.

Example:

192.168.56.101

## Subnetting

Subnetting divides a network into smaller logical networks.

## NAT

NAT (Network Address Translation) allows private IP addresses to communicate with external networks by translating addresses.
